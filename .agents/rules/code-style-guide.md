### Feature Implementation Guidelines

When implementing any new feature or modifying existing ones, the following rules apply:

1. **Automated Testing**: Always evaluate what new tests are needed and automatically write the unit/integration tests for the feature.
2. **Documentation**: Always update the `README.md` if the change introduces new environment variables, setup commands, or architectural concepts. 
3. **Quality Standards**: Write production-grade code. This includes proper error handling, logging, type hints, and ensuring it seamlessly handles edge cases. 
4. **Autonomous Execution**: Do not ask if I want these things done—consider them a mandatory part of any feature completion.
